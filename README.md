# 中文简介  
## **村民拾八模组整合（视频第4期）**  

### - 注意：由于视频需要，未考虑可玩性，所以该模组存在BUG多/玩法不完善等问题，且模组本身未来不一定会继续更新，仅供玩家体验。  
### - 目前模组只支持Java Fabric 1.20.4版本。  
### - 我发现似乎许多模组会与该模组产生冲突，不建议搭配过多模组进行游玩。  

    
包含内容:  

1.新生物：卫道士美女
- 该生物会在林地府邸自然生成，她会与大部分灾厄村民进行繁殖，然后生成新的卫道士美女，与卫道士美女繁殖的灾厄村民会因病在不久后死亡。  
- 该生物无法使用生物蛋生成，可使用指令/ **summon vindicator_beauty**生成:

      
# English
## **Integration of CunMin18's mod (video No.4)**

### - Attention: Due to the need of video, the playability is not considered, so there are many bugs/imperfect gameplay in this module, and the module itself may not be updated in the future, which is only for players to experience.
### - The current module only supports Java Fabric version 1.20.4.
### - I found that it seems that many modules will conflict with this module, so it is not recommended to play with too many modules.  


Contains content:

1. A new creature: Vindicator Beauty
- The creature will be naturally generated in the woodland mansion, and she will breed with most of the villagers in the disaster area, and then generate a new guardian beauty. The villagers in the disaster area who breed with the guardian beauty will die soon due to illness.
- It can't be spawned by egg.You can spawn it by command"/ **summon vindicator_beauty** ".
